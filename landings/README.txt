Папка для лендингов (F5 открывает её автоматически).

Как пользоваться:
1. Скопируйте сюда папку оффера (с index.html), например:
   landings/my-offer/index.html
2. В Cursor нажмите F5 (Run Extension).
3. В новом окне откройте index.html → Go Live.

Сюда можно кидать несколько офферов — каждый в своей подпапке.
Содержимое landings/ в git не коммитится.

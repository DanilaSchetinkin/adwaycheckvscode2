ADWAY CHECKER — VS CODE EXTENSION
Автор: Danila Schetinkin
GitHub: https://github.com/DanilaSchetinkin/adway-checker-vscode
==================================================================


1. ЗАПУСК
---------
Первый раз:
  1. npm install
  2. npm run compile
  3. Открыть папку в VS Code → нажать F5

2. ЧТО МОЖЕТ ПОЛЬЗОВАТЕЛЬ
--------------------------
В любом HTML файле нажать правую кнопку мыши:

  → Adway: Проверить лендинг       — проверка всего файла
  → Adway: Открыть все сниппеты    — меню вставки кода
  → Adway: Вставить код ▶          — быстрая вставка:
       · jQuery
       · Обязательные скрипты
       · Скрытые инпуты
       · Форму
       · Дату
       · HLS видео

  Ctrl+Alt+A  — проверить лендинг (горячая клавиша)
  Ctrl+Shift+M — показать все ошибки (Problems Panel)

  Автодополнение: печатать adway- и выбрать из списка:
    adway-jquery, adway-form, adway-scroll,
    adway-validation, adway-hidden, adway-date,
    adway-video, adway-viewport, adway-timer

  Кликнуть на ошибку в результатах → переход к строке кода.


3. ЧТО ПРОВЕРЯЕТ ПРОГРАММА
---------------------------
  · DOCTYPE html
  · jQuery 3.6.0 в <head>
  · Скрипт lazy loading
  · Скрипт прокрутки к форме + наличие id="oneform"
  · Скрипты валидации name и phone
  · Формы: 6 скрытых инпутов (fbpx, utm_code, cid, sid, hash, country)
  · Формы: action="/order.php" и method="post"
  · Инпуты name="name" и name="phone" с required
  · Ссылки href="#"


4. КАК ОБНОВЛЯТЬ ССЫЛКИ И ВЕРСИИ
----------------------------------
Все проверяемые строки находятся в файле:
  src/checker.ts

Примеры что и где менять:

  jQuery версия:
    Найти: headContent.includes('3.6.0')
    Заменить на нужную версию, например: '3.7.0'

  jQuery CDN адрес:
    Найти: headContent.includes('cdnjs.cloudflare.com')
    Заменить на нужный домен

  Обязательные поля формы (сейчас: fbpx, utm_code, cid, sid, hash, country):
    Найти: const fields = ['fbpx', 'utm_code', 'cid', 'sid', 'hash', 'country']
    Добавить или убрать нужные поля

  Action формы (сейчас: /order.php):
    Найти: formLower.includes('action="/order.php"')
    Заменить на нужный путь

  Сниппеты (тексты кода для вставки):
    Файл: snippets/adway.json
    Найти нужный сниппет по имени и отредактировать "body"

После любых изменений в src/ обязательно:
  npm run compile
  Перезапустить Extension Host (F5)

1. ЗАПУСК (РАЗРАБОТКА)
----------------------
Первый раз:
  1. git clone https://github.com/DanilaSchetinkin/adway-checker-vscode.git
  2. cd adway-checker-vscode
  3. npm install
  4. npm run compile
  5. Открыть папку в VS Code → F5 (Extension Development Host)

Обновление после git pull:
  npm install
  npm run compile
  снова F5
  (если менялся package.json — Reload Window недостаточно)


2. ЧТО МОЖЕТ ПОЛЬЗОВАТЕЛЬ
--------------------------
Открыть HTML лендинга → проверить / править.

Проверка:
  Ctrl+Alt+A  — Adway: Проверить лендинг
  ПКМ по редактору → Adway: Проверить лендинг

Где смотреть результаты:
  · webview «Результаты проверки Adway» (справа после проверки)
  · Problems (Ctrl+Shift+M)
  · Activity Bar → Adway → Results

Панель результатов (webview):
  · ЛКМ — переход к строке ошибки / предупреждения
  · ПКМ — команды исправления (jQuery, форма, пути, скачать картинку…)

Также:
  · Quick Fix (лампочка) у диагностики
  · сниппеты: печатать adway- (jquery, form, scroll, validation, hidden, date, video…)
  · ПКМ редактора: очистка, форма, пути, сниппеты, структура проекта


3. ГОРЯЧИЕ КЛАВИШИ (HTML)
-------------------------
На Mac вместо Ctrl — Cmd.

  Ctrl+Alt+A  — проверить лендинг
  Ctrl+Alt+C  — почистить лендинг (target, picture, href)
  Ctrl+Alt+F  — починить форму заказа
  Ctrl+Alt+P  — исправить все локальные пути (images/css/js)
  Ctrl+Alt+H  — заменить все href у <a> на "#"
  Ctrl+Alt+R  — показать панель результатов (дерево Adway)
  Ctrl+Alt+L  — вставить lazy loading
  Ctrl+Alt+V  — вставить валидаторы
  Ctrl+Alt+S  — вставить все обязательные скрипты
  Ctrl+Alt+M  — удалить HTML-комментарии
  Ctrl+Alt+D  — скачать внешние изображения из ошибок → images/
  Ctrl+Alt+O  — открыть внешние изображения в браузере (Save as)


4. ЧТО ПРОВЕРЯЕТ ПРОГРАММА
--------------------------
  · DOCTYPE html
  · jQuery 3.6.0 в <head> (CDN cdnjs)
  · Lazy loading, scroll к #oneform, валидация name/phone
  · Формы: 6 hidden (fbpx, utm_code, cid, sid, hash, country)
  · Формы: action="/order.php", method="post", required у name/phone
  · id="oneform", лишний <base>
  · Ссылки <a href> (#, offer, tel, mailto…)
  · target, <picture>/<source>
  · Локальные пути (подсказки images/ css/ js/)
  · Внешние изображения / CSS / JS (вне whitelist)
  · SID/Country (если настроен Sheets)
  · Пустые / дублирующиеся / неиспользуемые скрипты (эвристика)


5. ПОЛЕЗНЫЕ КОМАНДЫ
-------------------
  Adway: Создать структуру проекта
    → папки images/, css/, js/, other/, index.html
    (пустые style.css / main.js больше не создаются)

  Adway: Почистить лендинг
    → убрать target, flatten picture, нормализация href

  Adway: Починить форму заказа
    → action/method/oneform/required/hidden

  Adway: Скачать внешние изображения
    → только URL из ошибок «Внешнее изображение»
    → уже есть в images/ по имени — не качает снова
    → байт-в-байт дубли схлопываются (в уведомлении — какие файлы удалены)

  Adway: Обновить кэш SID/Country
    → перечитать Sheets


6. КАК МЕНЯТЬ ПРАВИЛА ПРОВЕРКИ
--------------------------------
Логика проверок:     src/checker.ts
Диагностики / фиксы: src/diagnostics.ts, src/codeActions.ts

Хоткеи / команды:    package.json

Примеры в checker.ts:
  · версия jQuery — поиск 3.6.0 / cdnjs.cloudflare.com
  · поля формы — fbpx, utm_code, cid, sid, hash, country
  · action формы — /order.php

После правок в src/:
  npm run compile
  F5 (перезапуск Extension Host)
